# Images Directory

This folder contains images for the Wagner Brothers fan site.

## Required Images

### 1. Orlando Magic Logo
**Filename:** `orlando-magic-logo.png` or `orlando-magic-logo.svg`

**Where to download:**
- **Wikimedia Commons (SVG):** https://commons.wikimedia.org/wiki/File:Orlando_Magic_Clear_Logo.svg
- **Loodibee (PNG):** https://loodibee.com/nba/orlando-magic/ - Download the current logo
- **FreeBie Supply (SVG/PNG):** https://freebiesupply.com/logos/orlando-magic-logo/
- **SeekLogo (Multiple formats):** https://seeklogo.com/vector-logo/621298/orlando-magic-2025

**Recommended:** Download the SVG version for best quality, or PNG with transparent background.

**File size:** Keep under 100KB for fast loading

---

### 2. Wagner Brothers Photo
**Filename:** `wagner-brothers.jpg` or `wagner-brothers.png`

**Where to find:**
- **Getty Images:** Search for "Franz Moritz Wagner Orlando Magic" (may require purchase/license)
- **Orlando Magic Official Site:** https://www.nba.com/magic/photos - Look for team photos
- **ESPN Photo Gallery:** Search team galleries for Wagner brothers photos
- **Orlando Sentinel:** https://www.orlandosentinel.com/ - Check sports photo galleries
- **Yahoo Sports Article:** https://sports.yahoo.com/how-the-wagner-brothers-are-helping-to-shape-the-magic-into-a-playoff-contender-154426135.html

**Tip:** Look for photos from the 2024 "Wagner Brothers" documentary or recent team events where both brothers are featured together.

**Image specifications:**
- Aspect ratio: 16:9 or 3:2 recommended
- Minimum resolution: 1200px width
- Format: JPG or PNG
- File size: Keep under 500KB (optimize if needed)

---

## Image Optimization

Before adding images to this folder, consider optimizing them:

**Online tools:**
- TinyPNG: https://tinypng.com/
- Squoosh: https://squoosh.app/
- ImageOptim: https://imageoptim.com/

**Recommended dimensions:**
- Logo: 200px height (maintains aspect ratio)
- Wagner Brothers photo: 1200px width x 675px height (16:9)
